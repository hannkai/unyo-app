■ 起動方法
1. rail_formation_manager.html を Chrome または Edgeで開いてください。
2. 初回利用時は「データを開く」からrail_formation_database.json を読み込みます。
3.「編成マスター」で編成名、車両形式、車両番号、所属車両区などを登録します。
4.「運用編成」で登録済みの編成マスターを選択し、必要な順序に並べて保存します。
5. 編集内容をファイルとして保管するときは「データベースを保存」を押してください。

■ 基本的な機能

【編成マスター】
車両形式・車両番号・連結順序・編成名・所属車両区・備考を編成単位で管理できます。
編成の新規登録、編集、削除に対応しています。
登録済みの編成をコピーして、新しい編成として登録できます。
1両目の車両番号をもとに、編成名の末尾に「F」を付けて自動入力する機能があります。必要に応じて手動で変更できます。
車両の追加や削除、連結順序の変更ができます。

【運用編成】
編成マスターを複数組み合わせて、実際の運用編成を作成できます。
運用編成名、列車名、走行路線、備考を登録できます。
使用するマスター編成の追加・削除や、連結順序の入れ替えができます。
一覧の表示を「編成単位」と「車両単位」に切り替えられます。

【検索・絞り込み・並び替え】
編成マスターは編成名・形式・車両番号・メモなど、運用編成は運用名・列車名・路線・編成名などを検索できます。
検索方法は「部分一致」と「完全一致」から選択できます。
部分一致：入力した文字列を含む項目を検索します。
完全一致：項目全体が入力した文字列と一致するものを検索します。
車両区や路線による絞り込みに対応しています。
並び替え項目を選択し、昇順・降順を切り替えられます。
一覧の表示を1列または2列に切り替えられます。

【一括編集・一括削除】
一覧から複数の編成マスターまたは運用編成を選択できます。
選択したデータをまとめて編集、または一括削除できます。
「表示中をすべて選択」を使うと、現在の検索・絞り込み結果をまとめて選択できます。
一括削除を実行する前に、対象データを確認してください。運用編成で使用中のマスター編成は削除できません。

■ データ名称・画像出力
編成マスターと運用編成の画面に、任意の「データ名称」を設定できます。
データ名称は画像出力にも表示されます。
一覧の画像をPNGまたはJPEG形式で保存できます。
画像出力前に、対象となる一覧や表示形式を確認してください。

■ CSV一括登録
画面上部の「CSV一括登録」から、編成マスターまたは運用編成をCSVファイルでまとめて登録できます。各データの「空のテンプレート」または「記入例」をダウンロードして使用してください。

【編成マスターCSV】
1両につき1行で記入します。同一編成の車両行には同じ「編成ID」を記入します。編成IDは利用者が自由に決める管理用ID（必須）です。
列：編成ID, 編成名, 所属車両区, 備考, 車両順序, 車両形式, 車両番号
編成ID・編成名・車両順序・車両形式は必須です。車両順序は1からの連番にします。

【運用編成CSV】
1つのマスター編成につき1行で記入します。同一運用の各行には同じ「運用ID」を記入します。
列：運用ID, 運用名, 列車名, 走行路線, 備考, 連結順序, 編成ID
編成IDには編成マスターの内部ID・CSV
ID、または一意の編成名を指定します。複数路線は「|」で区切ります。
同じ運用IDの全行で、運用名・列車名・走行路線・備考は同じ内容にしてください。

【CSVの検証・重複処理】
CSVを選択すると内容を検証し、行番号付きのエラーと登録前プレビューを表示します。
エラーがある場合は登録できません。内容を修正してから再度読み込んでください。
UTF-8（BOM付き／なし）とShift_JIS（CP932互換）に対応します。 
引用符で囲まれたカンマや改行を含むCSVにも対応しています。
既存IDと重複した場合の処理は「スキップ」が初期設定です。「更新」を選ぶと同じIDのデータをCSVの内容で置き換えます。
CSV登録は検証がすべて通った場合に一括反映されます。既存データを無条件に削除するものではありません。
CSV IDはデータベースに保存され、JSONの保存・読み込み後も保持されます。
記入例に含まれる車両形式・編成名などは説明用の架空データです。

■ CSV出力
「CSV出力」から、編成マスターまたは運用編成のデータをCSV形式で書き出せます。
書き出したCSVは表計算ソフトでの確認や、別のデータベースへの移行などに利用できます。
再度取り込む場合は、列名や必須項目、IDの対応関係を確認してください。

■ 保存について
編集内容はブラウザの localStorageに自動保存されます。
「データベースを保存」でJSON形式のデータベースファイルとして保存できます。
Chrome／Edgeなどの対応ブラウザでは、保存先ファイルを選択して上書き保存できる場合があります。
「データを開く」で既存のJSONデータベースを読み込めます。
別のPCやブラウザへ移行する場合は、JSONファイルを保存し、移行先で読み込んでください。
localStorageのデータは、ブラウザや利用環境に依存します。重要なデータは定期的にJSONファイルとして保存してください。

■ データ連携・注意事項
運用編成は編成マスターのIDを参照しています。そのため、編成マスターの車両形式・車両番号・所属車両区などを編集すると、運用編成側の表示にも反映されます。
運用編成で使用中のマスター編成は、誤削除を防ぐため直接削除できません。削除する場合は、先に運用編成から取り除いてください。
CSVの一括登録や一括削除を行う前に、対象データと内容を確認してください。
データベースファイルは定期的にバックアップしてください。

■ 対応環境 -
PCでの利用を主な対象としています。スマートフォンでは縦画面向けのレイアウトに切り替わります。 -
ChromeまたはEdgeでの利用を推奨します。 -
外部ライブラリやインターネット接続は不要です。
web版を使用する際はインターネット接続が必要です。
