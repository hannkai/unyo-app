鉄道編成管理アプリ（Rail Formation Manager）

■ アプリの起動はこちら<br>
<a href="rail_formation_manager.html">アプリ起動</a>

■ ファイル
- rail_formation_manager.html : アプリ本体。ブラウザで開いて使用します。
- rail_formation_database.json : 空のデータベースファイル。初回の読み込み用です。

■ 起動方法
1. rail_formation_manager.html を Chrome または Edge で開いてください。
2. 「データを開く」から rail_formation_database.json を読み込みます。
3. 「編成マスター」で車両形式・車両番号・所属車両区を登録します。
4. 「運用編成」でマスター編成を選んで追加し、必要な順序に並べて保存します。
5. データをファイルに保存するときは「データベースを保存」を押してください。

■ 保存について
- 編集内容はブラウザの localStorage に自動保存されます。
- 「データベースを保存」で JSON 形式のテキストファイルとして保存できます。
- Chrome / Edge など対応ブラウザでは、保存先ファイルを選んで上書き保存できます。
- 「データを開く」で既存の JSON データベースを読み込めます。
- 別のPCやブラウザへ移す場合は、JSONファイルを保存してから移行先で読み込んでください。

■ データ連携
運用編成は編成マスターのIDを参照しています。そのため、編成マスターの車両形式・車両番号・車両区を編集すると、運用編成側の表示にも反映されます。運用編成で使用中のマスター編成は、誤削除を防ぐため直接削除できません。先に運用編成から取り除いてください。

■ 対応
- PCを主対象とした画面構成。スマートフォンでは縦画面向けにレイアウトが切り替わります。
- アプリをダウンロードしてローカルで使用する場合、外部ライブラリやインターネット接続は不要です。


■ CSV一括登録（追加機能）
画面上部の「CSV一括登録」から、編成マスターまたは運用編成をCSVで登録できます。各データの「空のテンプレート」または「記入例」をダウンロードして使用してください。

【編成マスターCSV】
- 1両につき1行で記入します。同一編成の車両行には同じ「編成ID」を記入します。編成IDは利用者が自由に決める管理用ID（必須）です。
- 列：編成ID, 編成名, 所属車両区, 備考, 車両順序, 車両形式, 車両番号
- 編成ID・編成名・車両順序・車両形式は必須です。車両順序は1からの連番にします。

【運用編成CSV】
- 1つのマスター編成につき1行で記入します。同一運用の各行には同じ「運用ID」を記入します。
- 列：運用ID, 運用名, 列車名, 走行路線, 備考, 連結順序, 編成ID
- 編成IDには編成マスターの内部ID・CSV ID、または一意の編成名を指定します。複数路線は「|」で区切ります。
- 同じ運用IDの全行で、運用名・列車名・走行路線・備考は同じ内容にしてください。

【検証・重複処理】
- CSVを選択すると、文字コードを判定して検証し、行番号付きエラーとプレビューを表示します。エラーがある場合は登録できません。
- UTF-8（BOM付き/なし）とShift_JIS（CP932互換）に対応します。引用符で囲まれたカンマや改行も読み取ります。
- 既存IDとの重複時は「スキップ」が初期設定です。「更新」を選ぶと同じIDのデータをCSV内容で置き換えます。
- CSV IDはデータベースに保存され、JSONの保存・読み込み後も保持されます。記入例の車両形式・編成名は説明用の架空データです。
- CSV登録は既存データを無条件に削除せず、検証がすべて通った場合にのみ一括反映します。
